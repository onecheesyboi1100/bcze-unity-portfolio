# BCZE Unity Portfolio

Responsive Unity game-development portfolio (plain HTML/CSS/JavaScript).

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.
4. After deployment, the site should be available at:
   `https://onecheesyboi1100.github.io/bcze-unity-portfolio/`

## Customize
- In `index.html`, change the `BlueCheese` heading and intro paragraph.
- Edit the skill list below the intro.
- Each portfolio/project tile has `data-title` and `data-meta` attributes and matching visible text.
- Replace `YOUR_EMAIL@gmail.com` and `YOUR_DISCORD_ID` with your contact details.
- Replace placeholder tiles/modal content with your actual screenshots and video links as you add them.

No build tools or dependencies are required.
